# Security Policy

We take the security and integrity of the **AudioOutput Loupedeck Plugin** seriously. We appreciate responsible disclosure of vulnerabilities to ensure the safety and privacy of all users.

---

## Supported Versions

Only the latest active minor release of the plugin receives security patches and vulnerability mitigations.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability or security-related defect in this plugin, please follow these steps:

1. **Do Not Open a Public Issue**: To safeguard users, please avoid posting vulnerability details in public GitHub issues, PRs, or public discussions until a patch has been published.
2. **Submit via GitHub Private Vulnerability Reporting**:
   - Navigate to the repository's **Security** tab.
   - Click **Report a vulnerability** to open an advisory draft.
   - Alternatively, if private reporting is unavailable, reach out to the project maintainers directly via their listed profile contact info.
3. **Include Detailed Information**:
   - A description of the vulnerability and its potential impact.
   - Step-by-step instructions or proof-of-concept scripts to reproduce the issue.
   - Any proposed mitigations or fixes.

---

## Response Process & Timeline

- **Acknowledgement**: We aim to acknowledge receipt of vulnerability reports within 48 to 72 hours.
- **Assessment**: The maintainers will assess severity, reproduction reliability, and blast radius.
- **Remediation**: Once verified, a patched version will be built, tested, and released along with an updated security advisory and changelog entry.
